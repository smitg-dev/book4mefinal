# 📦 BookFromSpace 3D Assets Directory

Place your custom 3D `.glb` or `.gltf` model files here!

## How to render your `.glb` file:
1. **Option A (Drag & Drop)**:
   - Open `bookfromspace/index.html` in your web browser.
   - Click the **"🥽 3D VR Spaceship Interior"** tab.
   - Drag & drop your `.glb` file directly into the **Custom .glb 3D Model Viewer** box!

2. **Option B (Direct Asset Path)**:
   - Save your 3D file here as `bookfromspace/assets/spaceship.glb`.
   - In `bookfromspace/index.html`, set `<model-viewer src="./assets/spaceship.glb"></model-viewer>`.
